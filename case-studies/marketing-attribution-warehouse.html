01 / Overview

Connecting marketing performance to revenue

Marketing, CRM, and ecommerce teams each had a view of the customer journey, but those records did not connect cleanly. I designed a warehouse that joins engagement, registration, and purchase data, while recording how each link was established.

The original implementation used live organizational data. For the portfolio, I recreated the structure and attribution rules with generated records so the approach can be reviewed without exposing private information.

02 / Approach

Making attribution credible

Attribution is only useful when the matching rules are clear. The model gives exact email matches higher confidence than company-domain matches, and it keeps the match type with each result so analysts can distinguish stronger evidence from estimates.

I used Python and SQL to load a 32-table model, including the attribution fact table used by Power BI. The reporting layer follows the warehouse schema, keeping the measures consistent as source data changes.

04 / REFLECTION

Preserving the model when sharing the work

The first public recreation preserved the overall logic but changed fields the Power BI report still depended on. I revised the sanitization process to keep the required schema intact while replacing sensitive values. It was a useful reminder that the data structure and the reporting layer need to be maintained together.
